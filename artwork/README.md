# Clasp artwork sources

`clasp-app-icon-foreground-v1.png` is the original raster concept generated with
Codex's installed `imagegen` skill. The production Android launcher resources
translate that concept into deterministic `VectorDrawable` geometry so the mark
remains crisp, mask-safe, and themeable.

The icon is an original pair of inward-facing brackets clasping one signal-red
square. It must remain independent of Nothing logos, Glyph artwork, and
proprietary typefaces.

The small interface vectors under `app/src/main/res/drawable` use current
Material Symbols paths downloaded from the official Google Fonts asset service.
Material Symbols are available under the Apache License 2.0. The
`ic_clasp_rail` provenance mark is original Clasp artwork.
